# Changelog

## v0.1.0, 2026-09-17

Initial preserved developmental-attractor baseline.

The release includes a fixed-founder sparse recurrent developmental network, three information-rich developmental environments, a held-out 12-probe adult phenotype battery, developmental-firewall checks, noninvasive evaluation tests, paired counterfactual experience seeds, Windows launchers, and the preserved aggregate outputs from the 36-life extended experiment.

The extended result showed reliable developmental differentiation between canonical and matched-rich lives, but the early-computer-access ablation outperformed canonical development. The baseline is intentionally preserved with that failed secondary hypothesis intact. v0.2 is reserved for stronger context-conditioned action learning and a reward-matched ablation.
