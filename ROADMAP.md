# Roadmap

## v0.1 baseline: preserved

The current implementation is the fixed-founder developmental differentiation baseline. It should remain reproducible and should not be retroactively modified to make the initial hypothesis succeed.

## v0.2: contextual learning

The next milestone should change as little as possible while addressing the failure mode revealed by v0.1. Action values should become more strongly conditioned on internal and environmental state so that successful behavior in one context does not become a global default across unrelated probes.

A reward-matched ablation should replace the current early-computer-access ablation as the primary causal control. It should preserve novelty, autonomy, mentorship, difficulty, recognition, opportunity density, and reinforcement magnitude while changing the domain-specific affordances. This is necessary to distinguish an effect of early computing from an effect of receiving many rewarding opportunities to create.

The exact v0.1 founder seed, 12 extended-run experience seeds, developmental worlds, and adult phenotype battery should be reused for the first v0.2 comparison. That makes the architectural comparison paired rather than anecdotal.

## Later experiments

After v0.2, developmental trajectories should be analyzed explicitly rather than only at adulthood. Causal-edit experiments can then delay or remove mentors, recognition, domain access, failures, and other developmental events while preserving as much of the remaining life as possible.

Only after those controls are stable should the organism be broadened with richer autobiographical memory, persistent relationship models, affect residue, prospective commitments, unresolved concerns, and longer-term habits. Adding these earlier would make the current developmental effect harder to interpret.

A second distinctive, well-documented subject would provide the strongest later validation. The same generic architecture should be capable of occupying different adult phenotype regions under different developmental histories without subject-specific hardcoding.
